Project Overview:
Tikus Bakery is a complete e-commerce frontend application for a bakery shop, built with React, React Router, Context API, and localStorage for data persistence and caching.

Caching Implementation Explanation:

1. Product Data Cache:
   - Implemented in src/context/BakeryContext.jsx (lines 42-80)
   - On first load, simulates network delay of 500ms using setTimeout
   - Products are cached in localStorage with key "tikus-products-cache"
   - Cache includes data and timestamp for expiration tracking
   - 5-minute expiration: 5 * 60 * 1000 milliseconds
   - Subsequent visits within 5 minutes load instantly from cache
   - After 5 minutes, re-simulates network delay and refreshes cache
   - Cache structure: { data: productsArray, timestamp: currentTime }

2. Search/Filter Cache:
   - Recent searches cached in localStorage with key "tikus-recent-searches"
   - Maintains last 3 unique search queries (line 128: slice(0, 3))
   - Search suggestions displayed in navbar search dropdown
   - Filter selections cached per session using sessionStorage
   - Category filter persisted with key "tikus-category" (lines 13-19)

3. Cart Persistence:
   - Cart state cached in localStorage with key "tikus-cart"
   - Automatic sync on cart changes (lines 34-36)
   - Survives page refreshes and browser restarts
   - Includes product details, quantities, and timestamps

4. Order History Cache:
   - Orders stored in localStorage with key "tikus-orders"
   - Each order includes: id, date, customer info, items, total
   - Persistent across sessions for order history functionality

Technical Implementation Details:

- Context API Usage: BakeryContext provides global state management
- localStorage Usage: For persistent data (cart, orders, products cache, searches)
- sessionStorage Usage: For session-specific filter selections
- Cache Invalidation: Time-based expiration for product data (5 minutes)
- Performance Optimization: Instant loading from cached data when valid
- Data Structure: All cached data uses JSON serialization for storage
